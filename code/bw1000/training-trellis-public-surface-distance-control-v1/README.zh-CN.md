# TRELLIS.2 独立采样的表面距离对照

同一 BoomBox 几何经原版 GLB 写读及固定配准后，原两组独立 2048 点采样的 F-score@1% 为 0.17187。这次保留原点集和配准，在两个方向上分别求每个采样点到对侧 6,036 个三角面的最短欧氏距离，随后按原固定参考最长边的 1% 阈值计算精确率、召回率及 F-score。

同一表面对照的双向平均距离为 8.74e-8，F-score 为 1.00000。沿冻结 X 轴移动参考最长边的 2.5% 后，平均距离为 0.01056，F-score 为 0.51510。两个方向均保留 2,048 点分母。

`surface_distance.metrics(reference, prediction)` 接收各自的顶点、三角索引和固定面积采样点。输入使用既有固定配准与参考归一化。此指标用于开发集几何诊断。正式 T10 的点云 Chamfer-L1、F-score 及 A100 参考继续按原配方验收。

`run_control.py` 读取既有本机私有归档并生成独占结果。此次耗时 6.95 秒，完成 1 个开发对象的 CPU 对照。模型预测、设备试验、训练更新和盲测对象均为 0。
