# InternVL 八卡首微批逐字段诊断

该作业复用原八卡 Swift 图文配方、504 个初始训练张量、容器版本及 17 份模型文件的只读挂载。每个 rank 在执行首个模型前向之前写入字段路径、类型、形状及摘要，经原有 rank 间共识后退出。目标是定位原 `1087656.1040` 的输入不一致。

控制器使用单一时限起点，在同一节点运行零卡准入、八卡诊断和零卡清场。容器在创建 Swift 子进程前复核运行时与模型文件视图。Swift 进程有意退出的返回码、八 rank 元数据、日志中的退出位置和清场分别记录。批次含零次优化器更新，不计入正式吞吐或五项训练备队。

A100 首字段对照需从其独立的原捕获派生。原训练配方、运行和结果均保留在原路径。
