# CMU 到 WoodenMesh 身体骨架的几何候选

输入是通过 CMU C++ 参考交叉验证的完整录制，以及已冻结的腾讯公开骨架。第一步对全部 940 帧、20 个位置锚点按固定 12 轮优化关节旋转，保留 22 个身体节点的原骨长。以同一官方静姿为起点，位置 RMS 从 0.28556 降为 0.04131 骨架单位。两侧锁骨由下游锚点约束估计，叶节点的轴向旋转缺少位置观测。用独立的齐次矩阵 FK 重放校验保存输出，并核对旋转正交性和骨长。

第二步保持拟合的全部关节位置，沿时间选择每个单子节点关节的最小轴向旋转变化，并固定无法由位置观测到的叶节点相对旋转。全录制相邻帧最大跳变从 76.69° 降到 7.36°。重放位置变化上界为 `6.06e-14` 骨架单位。这个处理提供连续的旋转表示，仍缺原演员的对应轴向旋转观测。

第三步用固定九点二项式权重在局部 SO(3) 切空间滤波，边界反射，以原时间戳从 60 Hz 取出 470 帧的 30 Hz 序列。FP32 两列交错编码由原腾讯几何源码验证，再用正交化解码重放。完整 `[470,22,6]` 旋转数组的矩阵往返最大误差是 `3.70e-8`。滤波相对原 60 Hz 序列同时间戳的最大关节位移为 `0.00728` 骨架单位。

三次本机执行的原回执和数组留在 `local-only`。源码及摘要只记录身份、范围和聚合误差。当前仍缺绝对根平移标定、部署端骨架及统计身份、WoodenMesh 和原文本条件的真实执行，以及 A100 配对。旋转候选不能直接作为 135 或 201 维缓存，也不增加可调度训练计数。
