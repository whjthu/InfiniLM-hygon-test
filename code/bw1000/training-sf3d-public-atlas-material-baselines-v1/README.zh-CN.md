# SF3D 公开材质图集的开发集基线

冻结配方 `sf3d-public-pbr-UV-atlas-v1` 使用 WaterBottle 和 Corset 两个训练对象，并把 BoomBox 整对象留作开发集。本机执行比较两种预先固定的预测。第一种取两个训练对象标签的等权均值。第二种在 BoomBox 上运行冻结 SF3D 后端的原 RGBA 颜色启发式，并把其平均 sRGB 反照率转换成线性 RGB 后评分。粗糙度和金属度直接使用原启发式输出。

`material_mae.score` 以预定对象列表为分母，先对每个对象的 RGB 三通道求平均绝对误差，再对对象等权平均。粗糙度和金属度各有一个归一化通道。空缺或无效预测保留在失败分母中，并使整组 MAE 留空。原始材质向量留在本机私有结果。

BoomBox 结果覆盖 1/1 个开发对象。训练标签均值的反照率、粗糙度、金属度 MAE 分别为 0.0518、0.4485、0.2614。原颜色启发式分别为 0.1044、0.7334、0.0088。这些分项基线用于对照后续同配方原生模型输出。此次实测范围为均匀 UV 图集的单对象均值，盲测对象、原生模型预测和优化器更新均为零，固定视角 LPIPS 待测。

`run_baselines.py` 使用已冻结的训练与开发素材、框架归档和目标加载器，独占输出目录由首次运行创建。独立的评分边界测试可在本目录使用 `python -B -m unittest test_material_mae` 执行。
