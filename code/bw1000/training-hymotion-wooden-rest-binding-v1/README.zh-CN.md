# CMU 动作与 HY-Motion 官方静姿骨架核对

从腾讯官方固定提交 `4e426f5a1021cbcf7f375458c37b840ee7225229` 核验关节名、树结构、静姿和两份统计文件。四份二进制文件按完整 Git LFS 声明逐字节校验。公开模板包含 52 关节，前 22 项是身体骨架。两份统计均为 201 维有限值。按原缓存入口的 FP32 规则，有 3 项标准差低于 `1e-3`，生产器对这 3 项采用单位尺度。部署端的原模型和统计文件仍须另行核对。[腾讯静姿资产](https://github.com/Tencent-Hunyuan/HY-Motion-1.0/tree/4e426f5a1021cbcf7f375458c37b840ee7225229/scripts/gradio/static/assets/dump_wooden)

复用已经通过 C++ 参考交叉验证的全部 940 帧 CMU 录制。`bind_rest.py` 以静姿的髋线和脊柱定向，以两腿上、下段总长度作统一比例，把 20 个候选解剖锚点投影到与官方静姿同向的根相对坐标。两侧锁骨保留未绑定，需单独标定。17 条可比骨段包含超过 20° 的静姿方向残差。整体刚性对齐和尺度校正无法消除这些差异。

既有目标配置记录 30 Hz，本次 CMU 原录制为 60 Hz。仅统计两个原始时间网格的 470 个交点，尚未实施旋转感知重采样。原录制、公开资产原始字节及生成的 940×20×3 轨迹保存在本机实验目录。仓库保留校验值、公开来源、可复现源码及小型结果。

当前交付为静姿及位置锚点证据。正式 T08 配方、模型权重、首步参考和验收口径沿用原约束。完整关节重定向、文本条件、真实 128×201 缓存及 A100 配对仍待执行。
