# Original v2 independent read-only consumer

Root invokes read_original.py once after review. This reader hard-binds request
250e43f5a5b048f6bb2ca674e8a8ef44, publication b54b318c, original epoch and frozen
source MF853e4c. It first reads the five bounded original local records, then
uses each existing SSH route once for exact new v2 endpoint artifacts. It does
not rerun a stage, create a remote namespace, query Slurm or read original model,
shard, initial.pt, training JSON or any prior audit scope.

Source inspection reads only four new small files: intent, outcome, validation
and derived initial binding. The source compressed bundle is stat-only; its
persisted body is not reopened/rehashed. Its validation/outcome digest is crossed
with root's actual received compressed-stream hash and receiver's bundle digest.
Receiver streams hashes of the36 newly staged metadata/header/binding files.
Metadata bodies remain remote. Only bounded summaries, file pins,16 initial
dependency rows, historical reservation facts and process system costs reach L.

Both original owned PID/startticks must have exited on the matching boot/UID.
Resource receipts require two CPU affinity cores, actual nice10, AS512MiB and
finite real self CPU/wall/Linux maxrss-byte costs. Historical parent receipts
require RUNNING40/DCU320 each, numeric owner UID and80 unique nodes.640 means
reservation, not busy; this reader does not make a fresh utilization sample.

Transport/controller outcomes and the original v1 failure denominators remain
separate from independent metadata verification. UNKNOWN cannot authorize replay.
Any observer error leaves the original stage unchanged. Successful metadata
verification is not complete weight identity, tensor-copy verification,
cross-platform numerical alignment, model qualification, performance or effect.
