# 首次 USGS 领域 LoRA 训练：单次 A100 八卡

这是新领域配方的第一臂 fresh25，复用原生 LLaVA/Swift/HF 训练、冻结视觉、LoRA16/32/0.05、BF16、batch1乘8卡乘累积4、eager、关闭重算和25步cosine。独立45条图表训练输入通过固定800行视图提供；没有盲集、开发集评分或性能晋级。

安装器从已资格的 A100 原396源码复制到新私有400文件框架，只替换统一入口并加4个模块，不修改旧安装。源码、15个provider、原模型元数据和既有全权重SHA对应stat连续性核完，才允许唯一原始epoch的执行。

父监督器以真实.py启动，强Popen/session锚先持久化，再用GO门闩释放共同入口；入口再次核其真实身份与已资格清理helper。八卡准入只采一次，runtime probe后启动前同进程monotonic年龄必须不超过60秒。所有后代按原900秒范围清理，post仅核原8物理设备、进程与端口；UNKNOWN不重投。

首次领域臂实际保存504张量/43,646,976参数的initial文件和跨rank一致身份，供以后通用对照严格复用；首步学习率为0时仍记录真实AdamW状态，第二步要求非零实际变化。真实input/token曝光、25步、10/20/25全状态检查点和清理全部留在A100私有输出。尚未执行时不得称已有领域模型；训练loss/输入检查不替代效果、Hygon资格、正式吞吐或640卡busy。
