# HY-Motion 真实录制的胸椎相对颈部对照

在冻结的 940 帧 CMU 数据上核对胸椎和上颈椎的原旋转与骨段端点，两者方向误差低于 `1e-12`。用上颈椎相对胸椎的实际姿态替换目标颈部旋转。基变换由静态骨架和原颈部出射轴决定，按既有滤波和时间戳得到 470 个对应帧。公开统计只用于评估。FK 重放中其余 51 个关节位置逐元素一致，WoodenMesh 的颈到头骨长保持。

后 342 帧中，颈部最大绝对 z 值从 24.756 降至 2.816，头部对原固定锚点的位置 RMSE 由 0.03531 升至 0.13954 骨架单位。两种映射使用同一头部锚点和时间戳。结果表明，单独修正颈部旋转会把误差转移到位置。该映射未采纳。下一步应共同验证胸椎到颈部、颈部到头部的静态长度与活动枢轴，保留旋转和几何双重约束。

两个分段均来自同一录制。原始轨迹、候选数组和逐帧比较文件留在 `local-only/`。本轮没有生成训练缓存或执行训练，T08 正式配方与验收独立保留。
