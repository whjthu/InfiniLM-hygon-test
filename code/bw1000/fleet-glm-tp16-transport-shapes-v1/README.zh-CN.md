# GLM TP16 通信形状验证

沿用已验证的 Socket 和 SHCA 容器依赖与原 36 个节点对，每对使用一个 16 rank communicator，两个节点各用满八张卡。先跑四对，再依据每个形状的真实数值、数据通道和独立清场记录准入 36 对并发。保留两种固定消息形状，FP32 `[1, 6144]` 对应单 token 的 FFN collective，FP32 `[512, 6144]` 对应已测的预填块。形状来自 GLM474 原 318 结果，合成输入逐元素核对精确和 136。

每个 ABBA 臂逐形状 12 次预热、96 次计时。跨 16 个 rank 取每次调用的最大墙钟。每张卡在第 12、44、76 次操作返回后读取一次驱动 busy，读取在计时边界外。这些节点本地采样报告短时设备状态。整池同时采样、整模型收益和训练验收需各自实测。
