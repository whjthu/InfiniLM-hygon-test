# Explicit public fixed-C4 profile, source only

This private normal-import package is separate from r454/r457 and every live service. Native a314, HC0, r3660, fullpreOFF and policy0 are fixed. The default config has `experimental_profile: null` and `execute_authorized: false`; it cannot activate C4. Explicit `--experimental-profile deep-hc0-fixed-cohort-c4` selects rows4 and max_batch_size4. Source/config checks do not claim Model_READY. Original C1 public defaults are untouched.

`public_deep_cohort.cli` builds the original public InferenceServer and prepared producer. HTTP remains one request/response per request. An explicit top-level `native_fixed_cohort` ticket names one four-request closed group with row0..3 and serial/cohort caller mode. One group at a time is admitted. The producer preserves full history/template/strict4096 budget and publishes the same NativeRequest object to its owner thread. Native is created/loaded/finished/destroyed on that thread with eight internal workers, the exact original library/provider/memory/affinity guards and a new explicit rows4 typed descriptor.

The owner gathers exactly4, runs the original1417 continuation, emits first tokens before the next row prefill, shrinks EOS rows without refill, resets all rows before finishing any HTTP request, and drains cancellation/STOP/failure. Missing four-row groups fail after at most30seconds without partial Native execution. A cancellation during work cancels the whole closed cohort; this is intentionally not per-row online scheduling. Actual HTTP lifespan still belongs to the public server; no Native-to-HTTP join is introduced.

`pilot_inputs.py` freezes CPU945 first16 GSM + first16 MMLU, reusing complete original bodies, IDs and gold without reencoding or answer-dependent selection. All are known prior450 inputs and four overlap1417. `client.py` is the actual finite32-case/64HTTP paired client: four concurrent singleton HTTP requests per cohort, alternating pair order by group, no warm/extra request, qualitywrong/cap/parse retained and execution separated. Full wires and raw private inputs stay outside Git. HTTP chunks are not token clocks.

`check_local_CPU.py` has actually consumed the new production prepared factory, NativeRequest, owner loop, continuation, client main, public build_server/provider factory and Actors ready predicate. Five boundaries plus64 localHTTP requests pass, including all64 deliberately wrong answers with normal completion. Processor/Native/HTTP/READY are clearly recording leaves; no actual processor/Native/device/Model was invoked. `run_CPU.py` and CPU_RESOURCE_CLAIM describe the one necessary future R metadata/CLI/CPU945 handoff closure; it has not been submitted. No GPU controller is claimed complete. PILOT_PLAN budgets are a proposal requiring a separate concrete device claim.
