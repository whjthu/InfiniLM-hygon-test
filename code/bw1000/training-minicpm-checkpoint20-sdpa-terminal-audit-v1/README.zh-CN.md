# MiniCPM 原八卡 SDPA 对照终态复算

在海光登录节点用项目 Python 直接运行 `read_terminal.py`。待原 GPU 与零卡 post 的 Slurm 账务终结后，从四组各八份状态、就绪和停止记录重新核对 32 次前向。原检查点和逐 rank 参考从原实验路径读取，保留缺失分母并比对原 worker 汇总。程序还核验当次物理租约、同一开机身份的独立清场、端口和进程清理。

输出只包含边界、逐 rank loss 重复性、故障和原证据的校验值。没有模型加载、Slurm 提交或张量传输。本机 `check_local.py` 验证未终态、错编号、设备不洁和数值汇总不一致的边界。
