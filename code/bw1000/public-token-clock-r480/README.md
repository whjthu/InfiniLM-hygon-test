This opt-in overlay reuses the frozen r454 public entry, prepared admission, real P1 decoder/parser and worker. Native/math/weights/HC/FIFO/reset are unchanged. Default config has no token_clock_enabled=true; comments require BOTH that startup flag and header x-infinilm-token-clock: 1. Ordinary data frames remain byte-for-byte, and ordinary clients ignore SSE comments.

Build a new immutable package with build_overlay.py PARENT OUTPUT --parent-sha <DERIVATION exact parent SHA>. It retains the complete parent manifest schema/parent dependencies and changes only prepared-factory class composition, CLI class composition/private sink, native_decode return/sample hooks, and incremental_text progress observer. Run its normal python -m public_deep_model CLI with the new manifest SHA and existing validated configuration. Do not patch installed/running classes or old packages.

Client: collect_response(already_open_response, request_start_monotonic_ns, save_read=PRIVATE_R_SINK). It creates no HTTP requests. read1() records one timestamp for all bytes received in that read. Token notices share timestamps when coalesced; zero intervals stay zero, and no timeline is interpolated. No emission/server monotonic value is subtracted from another HOST clock.

Separate clocks: original CAPI return -> finite/sample -> NativeRequest.emit_token -> observer SSE yield -> ASGI send attempt/return -> actual client read. ASGI acceptance is not physical socket flush. Queue time is joined by existing private owner report request_id/started_monotonic and actual prepared acceptance metadata; stream start excludes prior HTTP parsing/validation. Private marker IDs/records are written only to runtime_directory/token-clock-private.jsonl and the existing private wire collector, never Git or product UI.

Token-ID receipt TTFT/rate/ITLs are distinct from semantic reasoning/content/tool TTFT. Empty text progress, incomplete Unicode tails, special IDs and EOS are separate. Existing P1 stable-prefix logic performs the decoding; no second tokenizer pass is added. EOS is retained but excluded from visible nonEOS rate. Nonstream bytes, a text chunk, and marker counts are never substituted for one decoded text token each. No semantic payload means semantic TTFT remains null. Missing/rejected/timeout/unfinished/cap cases remain in caller plan denominator; quality needs the existing independent scorer.

Bounds: native observer never blocks on HTTP. Queue is bounded by 2*8192+128 and rows by the original request output budget; overflow makes coverage incomplete, not a Native retry. Wire producer backpressure and Python observer work can alter scheduling, so record observer_emit_host_ns (emit wrapper only) plus ASGI/parser/sink cost separately in any future necessary Model run. This is source/local recording closure only, not measured real network/SLO/quality performance. No independent Model reload is authorized here.
