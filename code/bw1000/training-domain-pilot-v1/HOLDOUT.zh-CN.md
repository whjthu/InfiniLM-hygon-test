# 财政表格问答评测

开发集 108 题来自 36 张表，盲评 54 题来自 18 张表。三种题型等量。开发集用于调模型和固定解码配置，盲评只用于冻结配方后的最终比较。题目基于公开数据，盲评指项目内部隔离答案和调参流程。置信区间只覆盖这一数据源、这一表格版式和这一批时间段。

## 目标端输入

在持有已冻结数据的本地目录运行 `treasury_holdout.py prepare --source <原件目录> --split dev --output <新目录>`。先跑开发集，最终执行时用 `--split blind` 单独生成。原件 SHA、该划分的请求和图片清单 SHA 均由工具核验。输出只有 `manifest.json`、`visual.jsonl`、`text-only.jsonl` 与 `media/`。命令完全不打开 `labels.jsonl`，可在物理缺少答案文件的原件副本上运行。目标端只放这个生成目录，评分端持有原件和答案。首次本地实际派发前还需核对目标端每张图片和请求批次的 SHA。

目标推理复用现有 Qwen3-VL 底座、`qwen3_vl` 聊天模板和原生视觉处理器。媒体相对路径从生成目录解析。调用模型时只提交 `messages` 和对应图像内容，`id` 留在调用方供结果关联。无图对照使用 `text-only.jsonl` 的内容并确保没有图像特征、文件名和 ID 进入模型。完整处理 54 条盲评请求，每个臂使用同一顺序、光栅预处理、确定性解码及冻结的 token 预算。分开保存四组原始预测及摘要、模型和适配器内容指纹、生成配置与推理收据。

| 臂 | 权重与请求 |
|---|---|
| `base` | 初始化底座，视觉请求 |
| `domain` | 同一底座，领域 LoRA，视觉请求 |
| `generic` | 同一底座，等更新预算的通用数据 LoRA，视觉请求 |
| `domain_text_only` | `domain` 同一适配器，无图请求 |

通用 LoRA 冻结同一初始化及训练设置，记录数据、实际有效监督 token、更新数和批次。保留缺失、超时、截断、格式错和所有其他错误。每个预测文件为 JSONL，每行以 `id` 对应一个 `answer`。缺失可省略该行或写 `null`，后处理不补全原模型答案或取长解释中的数字。

## 评分

```text
python treasury_holdout.py score --source <原件目录> --split blind --output <新报告.json> --base <底座.jsonl> --domain <领域.jsonl> --generic <通用.jsonl> --domain-text-only <领域无图.jsonl>
```

金额用精确十进制判分，接受规范千分位和首尾空白，保留正负号及分位。日期要求有效的 `YYYY-MM-DD`。每臂保留全分母、正确、缺失、格式无效及错误计数。三个配对差异以整张表为抽样单位，固定种子抽样 10,000 轮，报总体准确率差和 95% 百分位区间。以对通用 LoRA 的增益作为领域适配主对照，并报告对底座和无图的差异。TextVQA 与 COCO CIDEr 能力按各自冻结评分器复评。保留预先确定的候选检查点、数据清单、同预算训练证据和失败预测。

本机已在无答案的原件副本分别实测 108 条开发、54 条盲评供料，且核对图像与无图请求结构。固定盲评视觉 SHA-256 `958bb7b241e7d7b86710be95c3b2096143c4abbf05d5c077997d6441bbd36029`，无图 SHA-256 `0aa4ec2fdfe2c55b29fb66c53a75576b1b990608a76cb0dc0baab734edd33b18`。评分器用冻结私有金标和合成预测验证全分母、缺失和无效计数、整表配对区间及重复、未知身份拒绝。模型预测、真实领域效果、等预算通用对照、通用质量和对外交付适配器仍待实测。领域连续训练和恢复结论以各自原始 GPU 记账和终态比较为准。
