# DeepSeek-v4 CSA 第 2 层拆分权重回执与加载

`bind.py` 核对 `.540` 返回的 16 段非 Indexer 原始范围回执。它将实际 23 项 header 与原 C4 Indexer 的 7 项 metadata 逐项对照，检查名称、形状、dtype、偏移、字节数、原配置、索引、分片头以及范围不重叠。只有原七段结果可见且已经独立固定该结果的 SHA-256，才会写出可消费的 23 段回执。该合并回执沿用 `csa-identity-swa-checkpoint-v1/inspect_checkpoint.py` 的 `bind_range_pins` 校验接口。

`load.py` 接受部署端绑定的同步 Native 参数调用。完成两个范围回执、原运行配置以及新建 TP1 `CsaAttention` 的 23 项未加载参数检查后，读取并核验全部 170,605,056 字节。每次在同一个文件描述符上核对原分片头，逐段读到独立缓冲并检查值摘要。所有缓冲就绪后才使用 `call("load", ...)` 和 `call("postload")`。Native 写入已开始但未成功完成时调用 `close()`。测量分别保留读取、校验和加载的完整耗时。设备调用者须提供实际 owner-thread、同步加载及可清理的 Native 实现。

13:33 的独立回读只取三条原证据路径。已核对 16/23 段值摘要，缺 7 段共 13,144,320 字节。原七段请求的执行状态仍未知，未重播。本机 8 项回归覆盖完整与缺失回执、伪造哈希、晚段坏值、Native 异常清理及 postload 超时。小型字节夹具用于测试加载顺序，正式权重加载和设备数值仍待验。
