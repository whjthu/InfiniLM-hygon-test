# DeepSeek CSA 提交观测的单对象构建

`prepare_stage.py` 以原 CPU1113 编译器、依赖和链接配方生成一个零卡构建包。它沿用已经验证的 TU07 真实调用点，观测实现和线程局部状态仅在 TU07 内部可见。新库允许增加三个强符号：`modern_deep_csa_commit_trace_arm_v1`、`modern_deep_csa_commit_trace_clear_v1`、`modern_deep_csa_commit_trace_read_v1`。原强符号、动态依赖顺序、库路径和传递依赖文件仍按同一原件核验。

生成包预期保留原 995 条依赖路径，加上观测 TU 和两个直接头文件，合计 998 条。`array`、`cstddef` 和 `cstdint` 已在原依赖中。开始目标编译前必须实际验证 `-M` 文件，编译后再按相同预期核对 `-MD`。链接只替换 TU07 的一个对象，复用其余 49 个文件。目标步骤沿用 300 秒单起点预算和隐藏 GPU 的原环境。原编译产物以及无观测构建的命名空间均保留。

`check_stage.py <本机生成目录> <私有的原 CPU1113 收据>` 复核生成阶段清单、真实依赖计划、对象顺序和新增导出限制。命令用替身核验顺序和坏输入，实际目标端 GCC、动态链接及 Slurm 结果需另行记录。观测库未来只用于设备数值和路由证明，正式性能用无观测路径度量。
