# DeepSeek CSA 单对象零卡编译入口

用 `prepare_stage.py <新目录>` 生成部署包。包内保留原 CPU1113 的工具链清单和环境脚本，以原环境前缀启动 `compile_once.py`。候选源码和 TU07 计划按已发布 SHA 校验。stage 清单、源码、父收据与实际工具字节都在编译前复核。

编译入口供后续经共享队列认领的零 GRES Slurm 步使用。入口要求父作业、原节点、4 CPU 和带单次起点的 300 秒预算，并隐藏设备。它先核实原库、原 MD 和既有依赖，运行一次 `-M` 并比对路径和文件 SHA，随后才执行一次 HOST 编译。实际 MD 和其余 49 个对象通过后才能链接。新库的强导出、动态依赖顺序、加载路径及对应库 SHA 要与原库一致，失败和中断保留在原输出目录。

本机已从真实 CPU1113 收据生成九个成员，核对 Python 3.10 语法和原环境前缀的 Bash 语法。顺序和拒绝条件使用替代命令回执验证，共 12 个反例。实际目标安装、构建认领、Slurm 记账和目标编译仍待完成。设备数值、上下文和延迟随后另行实测。
