# HY-Motion 的官方 CLIP-L 安装准备

T08 使用 OpenAI CLIP ViT-L/14 的固定版本。安装范围包含 6 个配置和 tokenizer 文件以及一份模型权重，共 1,714,256,158 字节。逐文件大小和 SHA-256 见 `claim.json`。实际流式安装仅涉及登录节点和项目存储。

本地发送端从固定版本的官方 HTTPS 地址读取数据，经既有认证 SSH 连接发送，每次最多读取 512 KiB。接收端分别核对 7 个文件的字节数和 SHA-256。只有收到发送端的完整校验确认、流正常结束并写好接收凭证后，接收端才将暂存目录改名为安装目录。目标目录、暂存目录和独占锁与本次标识绑定。失败时保留原记录，连接中断时按原请求和接收凭证核对。

`check_local.py` 使用小型内存输入验证发送、接收、重复执行和范围校验。当前验证只覆盖本机代码，集群安装和真实权重校验尚未执行。后续以独立读取的原接收凭证和文件摘要确认安装，再验证 HY-Motion 编码器的实际输出和训练数据准入。
