# Explicit qualified Kimi public provider

This is an opt-in source adapter for qualified **8df / TP16 / PP2 / C1 / 32768**. It does not change the generic engine, installed package, r425, or any default. It does not select the slower experimental 6eb TP8/PP4 backend. GPU/Model execution is not authorized by this package.

The current public `InferenceServer(engine_factory=...)` owns the ordinary HTTP app and lifespan. The new `KimiProvider` owns one same-process leader0 thread; the other three CLI leaders use the original four-participant `StageControl`. Each leader's Native context owns eight internal workers. TP groups are nodes0/1 and2/3, PP partitions remain `[0,46)` and `[46,93)`, sampling stays node2, and the queue stays node0. Python requests, locks, codec and queue never cross a process/socket boundary. Selected token IDs return through the original control collect.

`owner.py` statically retains the qualified create/layout/capabilities/key census, shard-head contract, 4GiB all-owner guard, bounded 2GiB checkpoint staging, finish and destroy code. It calls the original W512 input producer and original width1 greedy generation. There is no draft model, experimental admitted-request table, private HTTP app, BASE slicing or `exec` loader. The 24 transplanted runtime modules differ only in private sibling-import qualification and newline normalization; `DERIVATION.json` contains parent hashes and AST equivalence evidence.

The trusted CLI is `python -m public_kimi_native --config ... --config-sha ... --source-sha ... --node 0|1|2|3 --run ... --nonce ... --actual-step JOB.STEP --gpu-start-epoch ...`. Without `--serve`, it validates source/config/environment/topology only, without Torch or Native imports. The template has `execute_authorized=false`; it is **not a Model or Slurm resource claim**. A future explicit deployment must supply the common original epoch and the four actual leader identities, reserve the existing Native/control/HTTP ports, and use the qualified loader environment. No new launcher or automatic resource submission is included.

Before device preparation, each executing leader exclusively claims its own immutable run/node file. It checks actual Slurm role, hostname, trusted package hashes, qualified model manifest and fixed AR policy. `prepare_public` uses the current r425 public Python tree with the **old Kimi Common extension** `2e145860...` and runtime `04a6a1a8...`, not GLM's extension/SDK. The qualified Native binding still checks old receipt/objects, exact 8df symbol providers and SDK maps before create. Read-only Common binding-source evidence confirms `_core` is present; actual new public-module import with this extension has **not** been executed on devices or promoted to Model qualification.

Shutdown closes admission under the same lock as enqueue, marks cancellation, and lets the original request reset and four-leader destroy barrier finish. Queued requests finish only after owner join. Native never holds or joins HTTP. An unreturning Native owner thread causes fail-stop of its owned leader at the original bounded cleanup deadline; there is no retry/restart. Independent cleanup attempts sampler, Native destroy and control close while retaining primary and cleanup errors.

The original K3 codec/history contribution proof, context/output limits, greedy sampling, EOS and request retirement remain. Normal output defaults to4096, the inherited explicit limit is8192, and full prompt+budget must fit32768 without truncation. The inherited queue buffers visible text until completion. This source adapter does not claim incremental SSE latency, online SLO, broad quality or performance improvement.

`check_CPU.py --output local-CPU-result-final.json` exercises the actual public constructor/lifespan/factory and sampling methods, actual prepared queue/history, original AR producer, four actual local TCP controls, pending cancellation, primary failure/cleanup, and the final four-role CLI source/config path. It records Native/device/weights/codec/FastAPI leaves and POSIX hostname/file mapping. It is not an installed full public-module import, actual checkpoint encoding, new numerical test or device proof. The first local recording-leaf schema failure is retained in `FIRST_LOCAL_FAILURE.json`.
