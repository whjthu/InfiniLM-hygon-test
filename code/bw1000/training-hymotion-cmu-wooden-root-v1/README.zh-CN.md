# HY-Motion 根平移标定与 201 维几何预览

基于 CMU 实测根轨迹和已冻结的 470 帧旋转，通过同时间戳的九点滤波、骨架髋线偏航与原腿长比例，把平移换到公开 WoodenMesh 坐标。水平原点取第一帧。竖直平移只用前 128 帧实测趾端的低速触地条件标定，随后核对同一录制的其余帧。

从腾讯固定提交读取三份公开蒙皮资产，按 Git LFS 大小和 SHA 校验。真实 24,256 个顶点只对双脚低处各 217 个有足部骨权的顶点计算动态蒙皮。前段 128 个单脚接触观测用于偏移。后段 342 个接触观测的地面高度偏差 RMS 为 0.00594 骨架单位，绝对值 P95 为 0.01486。足端与地面只是本录制的标定依据，演员真实接触没有独立标注。[腾讯 WoodenMesh 源码](https://github.com/Tencent-Hunyuan/HY-Motion-1.0/blob/4e426f5a1021cbcf7f375458c37b840ee7225229/hymotion/pipeline/body_model.py)

保存 470×135 源输入和 470×201 CPU 几何预览。这 201 项按真实源代码组成，分别为根平移 3 项、身体旋转 132 项和模型局部关节点 66 项。原 WoodenMesh 前向仅将全局平移加到顶点，因此最后 66 项不加该平移。同一统一框架入口已实际通过一条完整 128 帧源输入检查，未执行原 Torch BF16 body model 或文本编码。

按公开统计，根块最大绝对归一化值为 0.66，旋转块为 26.09，最大异常位于颈部。另以首段选择一次不改变位置的固定轴向偏移，在后续 342 帧诊断。该偏移没有降低最大异常，颈部 RMS 从 9.503 升到 9.528。保留原候选，本次偏移不采用。后续需检查颈部对应关系以及部署端的真实统计、身体和文本编码身份，再生成训练缓存与 A100 配对。原录制、顶点、输出数组和逐帧轨迹留在私有目录。
