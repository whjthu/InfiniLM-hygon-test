# SDXL 科学图表训练目录校验

将冻结的 12 张训练图搬到目标服务器时，先在目标目录核对文件集合、训练元数据和每张 PNG 的实际字节，再把校验后的绝对路径交给共同框架的 SDXL 入口。公开清单只含路径相关摘要、文件摘要和冻结配方，训练文件名和文本留在私有目录。6 张开发图仍用于评估。

`entry.run_via_common_backend()` 要求调用方提供已核实的部署训练脚本 SHA256，并接受共同框架中两个登记的 SDXL backend。调用方应将目标数据放在作业期间固定的目录。配方为 25 步、256 像素、batch 1、rank 4、BF16，额外保存全局步 20 和 25。共同入口采用 constant 调度和零学习率预热，5 步 warmup 仅用于计时排除。

本地验证复制了真实的 12 张图和元数据。冻结 gencuda backend 的真实函数接到搬迁后的目录，在唯一原生子进程调用处截停。相对路径、额外目录、缺图、等长图片改动、等长元数据改动和错误训练脚本 SHA 各被拒绝一次。测试训练脚本是显式哨兵，部署端脚本身份、原生 ImageFolder、tokenizer、VAE 和参数更新仍待实测。
