# Kimi 末端残差投影的 64-token 分片

当前只准备候选源码与本机 CPU 验证。候选限定为原 R461 行并行词嵌入、Hygon TP32/PP1、batch 1、512 个输入 token、9 个残差状态和 BF16。环境开关 `INFINILM_KIMI_OUTPUT_RESIDUAL_TILE64=1` 准入，默认保留原方法。decode、其他宽度及图捕获继续进入原路径。

分片仅处理外层 token 轴。每片沿完整 7168 hidden 维做原归一化和投影，共拼回 512×9×1 分数。随后保留原整体 softmax 和对原始残差值的聚合。每片显式等待原 Runtime 流完成再释放临时张量，额外增加八次拷贝和八次流同步。F32 输入转换的行数从 4608 变为 576，仍在原 prefill 路由声明的 512 行范围内，实际调用的算子路径待目标侧核查。

两个主要临时请求的解析差值合计约 165.4 MiB。显存水位、驱动分配和耗时均待设备验证。原作业差额约 282 MiB，记录未定位低水位发生的算子。独立设备验证要采集实际入口、同输入 BF16 输出、端到端算子耗时和设备显存；达到模型准入条件前保留原整模型资格结论。

`python -B check_residual_tiles.py` 编译实际修改的方法体。CPU 记录式替身验证八片偏移、分数拼回、原聚合调用、临时张量持有、拷贝失败清理和五种回退输入。
