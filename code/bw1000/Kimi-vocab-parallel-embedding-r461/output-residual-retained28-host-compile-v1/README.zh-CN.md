# Kimi retained28 的单翻译单元编译

此入口使用 O01 的 f12r2n10，计划 4 CPU、8 GiB、0 卡，绝对预算 300 秒。候选使用之前冻结的同一 score 内核。生成 worker、编译计划和终态审核统一登记一个翻译单元。生成包的内核 SHA 与既有 retained28 源完全相同。

调用先核父作业、节点归属、现有编号 step 和唯一标签，再保存原意图。目标只执行 fresh M、编译、MD 和导出检查。终态检查实际 Slurm 资源、编译参数、对象、依赖闭包和符号。对账复用同一个请求与输出文件。

下一次可发布的设备资格还需对照实际基线与候选的 gfx936 指令、VGPR、scratch 和溢出，再以完整 score 和最终输出及配对暖计时验证。本机回归覆盖单对象成功、绑定双对象数时拒绝、超时对账和防重提。
