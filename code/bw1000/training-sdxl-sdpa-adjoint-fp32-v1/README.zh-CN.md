# SDXL 首步注意力反向数值对照

原 528 记录中，5 个注意力区的 1120 个训练张量都贡献了参数更新误差。误差最大的 3 区即使完全修复，完整更新的相对 L2 仍约为 5.45%。原 475 的精确 A100 损失梯度、480 的 LoRA B 权重梯度和 540 的冻结卷积输入梯度实验均未通过 5% 更新门槛。下一项对照选择这 5 区共享的 SDPA 反向计算。现有证据用于选择覆盖范围，尚未证明 SDPA 是误差主因。

`intervention.replay_once` 使用原首步 worker 读取固定输入、原 A100 参考、权重和初值。原 SDPA 前向在原 grad mode 下执行，并保留原始输出字节。反向只替换 Q/K/V 的 adjoint，以 FP32 分块重算 softmax 和梯度，按原 dtype 写回。实际运行须覆盖全部 140 个 attention site，并核最终原 HIP BF16 前向输出 SHA-256。非原注意力范围继续使用原函数。只接收本用例的零 dropout、无 mask、非因果、等头数路径，部署时若组合不符则保留为失败。改变了反向的计算与存储成本，需要独立测量。

`check_local.py` 用 88 个有限差分、跨两个完整分块与尾块的稠密 FP64 CPU 参考，以及真实 528 记录的区段张量数验证公式和范围。数值夹具为本机 NumPy 合成张量。当前交付含首步 worker 接口，尚需接入冻结的目标启动包和设备准入。

目标配对沿用同一 Hygon 首步的原始更新和 1120 张量比较。只有前向 SHA、完整反向覆盖和原 5% 更新门槛均合格，才有依据评估连续训练。此处尚无目标 PyTorch、GPU、训练、性能或正式验收结果。
