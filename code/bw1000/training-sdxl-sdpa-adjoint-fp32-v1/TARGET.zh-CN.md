# SDXL 注意力反向首步对照的目标运行包

`render_target.py` 将候选接到原 Hygon 首步的设备检查、环境、UNet、固定 A100 材料和完整比较器。目标包包含 18 个文件，其中 10 个成员逐字节复用原 540 运行包。独立比较器仍核对全部 1120 张量与原 5% 更新门槛。

本次只允许请求 `a93d41a0d31140f1ad99bb105a024e99` 在 `1087656` 的 O01 节点 `f12r3n20` 使用 1 DCU。根协调者先用目标的原请求状态、节点归属及当前设备证据取得调度预约，再向 `launch_once.launch(publication, request, transport)` 提供既有认证 transport。启动器核对普通 Git 发布字节、生成包 SHA-256，并在调用 transport 前独占写入本机原意图。目标包也按原请求独占创建目录。已有意图或响应中断时，从本机原意图、目标 controller 和实际 Slurm 句柄对账。

作业先提交零卡 PyTorch 原生桥接验证，包括真实 BF16 前向和反向、三个几何范围、BF16 写回与精度策略恢复。成功后取得新的设备收据，再提交原首步单卡对照。GPU 终态确认后做独立清场，随后由零卡步骤执行原比较器。全流程使用同一 host epoch 和 1200 秒上限。

本机包级回归使用真实打包与目录写入，模拟进程和传输边界。实际目标 PyTorch 步骤、单卡更新、清场和数值验收均待集群执行。
