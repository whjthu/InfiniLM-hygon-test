# InternVL USGS72 八卡领域训练

复用统一 Swift 原生图文入口、原 25 步学习率调度、八卡 BF16、每卡 batch 1、梯度累积 4、LoRA rank 16、SDPA 和梯度检查点。在第 2 次真实优化器更新后正常停止。首步记录零学习率下的优化器状态推进，第二步核对实际 LoRA 参数变化。

本作业使用 72 条 USGS 领域样本。每个实际训练微批经过 Swift 原生输入准备前，核对输入 IDs、未选择标签与像素摘要匹配的唯一域样本。模型前向前再核对实际标签和选择掩码。八个 rank 完整记录 64 个微批及前向、梯度裁剪与优化器边界，仅写摘要。复用原 rank 0 初值并广播核对。A100 其余 rank 的 RNG 尚未对齐。

正式原配方、A100 数值对照、25 次连续更新及留出集验收仍需要各自完整证据。派发前应核目标模型与输入、原节点租约及本次独占请求。
