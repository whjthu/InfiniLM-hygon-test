# MiniCPM LoRA dropout 原生掩码观察

这个观察器用于定位检查点恢复后同输入前向的差异。它要求原 LoRA 模块每次只调用一次实际 `aten::native_dropout`，保留算子返回的布尔掩码和原输出。完整前向返回后才将掩码逐个复制到 CPU 计算 SHA-256，结果不保存原始掩码。可比较的两臂需绑定同一 rank、检查点、输入、路由和顺序，并核对全部 186 个掩码。

运行时按掩码实际设备存储大小限制保留量。此观察会延长掩码生命周期，也会增加前向结束后的拷贝成本。原生回调接入 `native_plugin.py` 已冻结 u1、c1、c2、u2 四臂的观察范围。u1/u2 复用原 profiler，c1/c2 加入掩码观察。保持同一 SDPA 路由，可以检验加入观察器后原 loss 差异是否仍出现。当前接口仅验证了本机模拟调度，尚待启动器接入和原八卡实测。

用 `check_local.py` 验证单次原调用、延迟拷贝、预算、异常恢复及顺序核对。HIP 若未暴露原布尔掩码，该用例会失败并保留未完成的分母。
