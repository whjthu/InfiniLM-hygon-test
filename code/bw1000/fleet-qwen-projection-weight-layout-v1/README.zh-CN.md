# Qwen BF16 常驻投影权重布局短测

复用已经在 608 卡实际跑完的 BF16 投影算子及两父分片入口，固定 M=184、K=4096、N=1024 和每 64 次提交同步一次。前一轮比较同步次数，M=184 的高深度在全部 608 卡上提高有效行率。本轮只改变输入权重的物理布局。A 使用原 [N,K] 连续存储的转置视图，B 使用同值的一次性 [K,N] 连续预转置，按 A/B/B/A 每段测 5 秒。每臂交替两份非等价输入，逐元素对照完整 BF16 输出并独立核对 CPU 参考列。记录预转置耗时、额外常驻显存、有效行率和摊销调用数。用合成操作数验证布局机制，训练和服务指标仍待对应模型工作负载。

根协调者发布并启用 Claim 后，以现有 `launch.ship(publication, snapshot, transport)` 准入。每个新鲜、整节点 8 卡、无活动步和 KFD/PID 占用的候选可加入。高优先级及原未对账的预约保留，已知的两个外部 KFD 节点排除。两父各 40 节点，按资源分区切成最多 4 节点的独立步骤，每节点 12 CPU、24 GiB。整个控制器 240 秒，设备预算从原 epoch 计 210 秒。实际计划分母取新鲜快照，现有 640 卡分配不能证明全卡当前可用。

每片预先记录原请求和共享队列句柄。目标会重查父分配与本轮编号步骤，后来有冲突的片整片保留不派发，并写出原阻塞节点。设备终态及独立同父 PCI/KFD/PID 清场由根按原句柄结账。每卡保留 4 个计时槽、2 个配对及一次预转置成本。跨节点同步忙度需要另外用已合格全池脉冲采样。
