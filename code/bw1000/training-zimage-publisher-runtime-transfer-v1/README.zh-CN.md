# Z-Image 官方运行权重续传

接收器固定 19 个底座运行文件及一个 Turbo preset 的已发布来源、版本、字节数、SHA 和目录布局。Windows 侧每次在内存中读取至多 32 MiB，重定向仅允许官方 HTTPS 域。体积不超过 256 KiB 的非张量元数据可接收完整 200 响应，须同时吻合原件字节数及 SHA。权重只接受精确 206 范围。

每次传输先查询目标持久偏移，原子提交偏移与分段摘要。超时结束本窗口，后续先查目标原偏移。目标逐件闭合整文件 SHA 后，可用 `receiver.py publish` 核验并原子发布完整运行目录。逐件封存只写私有组装目录。校验前不对训练入口提供半套权重。

传输包复用已验证的接收器底层写入工具和现有 SCNet 认证链路，不提供新的凭据、网关或代理。此范围只配置公开权重文件，原 A100 捕获及 COCO20 原件继续由各自的组件证据关联。
