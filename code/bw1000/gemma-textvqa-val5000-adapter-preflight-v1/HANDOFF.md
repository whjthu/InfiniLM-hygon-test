# Gemma adapter-aware TextVQA Val5000

Run `python -I -S -B -X utf8 check_local.py` for local validation. All requests in that check use fixtures. `native.enter_arm` is the owner-callable runtime entry. There is no transport, scheduler or default model invocation.

The three scorer identities are the original A100 CP25 adapter, original Hygon USGS CP25 manifest and actual `.851` target-created initial named LoRA. The Hygon checkpoint manifest supplies the original adapter payload and config pins. The initial arm uses the original pinned restricted `.pt` state and original Hygon config. All arms verify the original 476 weights and 29,802,496 values against the structural manifest before constructing a private adapter directory. Runtime uses the `.3682` Swift dynamic `AdapterRequest`. The template checks the named request and the actual LoRA layer forward checks that the adapter is enabled, unmerged and selected in PEFT. It verifies every loaded value at initial activation and preserves parameter identity/version on subsequent calls. Any unproved route forbids publishing a prediction as scored.

The answerless input contract needs the frozen `c3e42949…` ordered identity projection, a separately pinned question-text-only projection, and the 3,166 exact publisher image byte/readback receipts with zero original-64 encoded overlap. The formal evaluation prompt is the historical TextVQA short-phrase prompt with greedy 32 tokens and the shared Gemma template. The older earthquake `.3682` prompt and 256-token policy are separate. All 5,000 questions per arm have one ordered prediction or explicit failure record. `contract.scorer_manifest` produces the three-arm binding consumed by `tools/textvqa_effect.py` after independent terminal checks. The annotation answer file is a scorer input only and never enters `native.enter_arm`.

Before any real run Root must establish the complete payload-validated media and answerless text bundle, A100 and Hygon runtime provider identities, original model/adapter file accessibility on each named platform, and separate execution/independent post. The A100 same-Val5000 predictions remain missing. The historical publisher ZIP index is membership evidence and cannot satisfy the media payload gate. This package records zero real inference or scoring and grants zero readiness.
