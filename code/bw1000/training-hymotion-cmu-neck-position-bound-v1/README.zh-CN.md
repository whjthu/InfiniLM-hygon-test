# HY-Motion 固定胸椎和颈部枢轴时的头部位置下界

沿用原录制的 470 个采样时刻、头部锚点、Spine3 姿态、Neck 枢轴和 WoodenMesh 骨长。颈部第 78 通道的 5σ 诊断线对应局部旋转约束 `R[1,1] ≥ 0.6295014`。这是分析用阈值。正式 T08 验收继续使用原配方和参考。

设骨段静止时与局部 y 轴的夹角为 β，`R[1,1]` 约束允许 y 轴转过不超过 α。旋转后骨段到 y 轴的夹角只能落在 `[max(0,β−α), min(π,β+α)]`。保持目标方向方位角并将其极角投影到该区间，得到最近的骨段终点。程序为每帧构造可达的三维旋转，独立复核正交性、旋转行列式、通道约束和理论距离。

| 同一录制范围 | 原头部 RMSE | 单通道约束下最低头部 RMSE | 位置误差必然增大的帧 |
|---|---:|---:|---:|
| 前 128 帧 | 0.04507 | 0.09617 | 128/128 |
| 后 342 帧 | 0.03531 | 0.09271 | 342/342 |
| 全 470 帧 | 0.03821 | 0.09367 | 470/470 |

后 342 帧若保持父姿态和骨长，想逐帧回到原位置误差，仅靠平移枢轴至少需要 0.07394 骨架单位的 P95 位移。这个下界允许枢轴自由平移。后续应先核对实际胸椎姿态和颈部枢轴约束，再同时验证位置与旋转。逐帧旋转和几何数据保存在私有目录，本轮训练和 GPU 调用均为零。
