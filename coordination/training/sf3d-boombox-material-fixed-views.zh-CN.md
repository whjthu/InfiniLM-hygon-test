# SF3D BoomBox 固定视角材质参考

以 BoomBox 为开发对象，冻结原 glTF 场景、几何缓冲、Base Color 和 ORM 纹理。应用场景节点变换，再按参考物体最长边统一尺度。三幅 256×256 的正交视角共用这个坐标系，画幅为参考最长边的 1.8 倍。逐像素取最近表面，按同一套 UV 采样 Base Color、粗糙度和金属度。PNG 保存无光照的 Base Color，参考包保存前景 mask、可见 UV 和 ORM。原始图、纹理和逐像素参考保存在项目私有目录。

将 WaterBottle 与 Corset 两个训练对象的材质标签等权平均，作为常量预测。按视角分别计算前景像素的线性 RGB、粗糙度和金属度 MAE。三个视角分别覆盖 14,844、14,500 和 13,728 个前景像素。视角等权 MAE 分别为约 0.2203、0.4644 和 0.3492。

该数据用于独立公开材质配方。后续保持同一相机、坐标系、光照协议和评分分母，对照目标模型输出。当前记录只有开发参考和常量基线，正式固定视角 LPIPS、原八张 RGBA 的 T11 验收及目标训练仍待实测。
